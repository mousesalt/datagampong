## Perlindungan Data

Jangan memasukkan file Excel penduduk, CSV, NIK, No. KK, atau data pribadi
ke repository publik. File `*.xlsx`, `*.xls`, dan `*.csv` sudah dimasukkan ke
`.gitignore`.
