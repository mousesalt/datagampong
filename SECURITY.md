# Security Policy

## Owner

**FARIDZOEL MOSSAL** is the project owner/maintainer for DATA GAMPONG.

## Sensitive Data

This application works with population data such as NIK, No. KK, names,
family relationships, education, occupation, and other personal information.

Do **not** submit real population data, exported Excel files, screenshots
containing personal data, or credentials to public GitHub Issues or Pull Requests.

The repository `.gitignore` intentionally excludes Excel/CSV population data
from Git tracking.

## Reporting a Security Issue

For a security issue involving the source code, please contact the project
owner privately rather than publishing exploit details in a public issue.

## Scope

This policy covers the DATA GAMPONG source code maintained in this repository.
Third-party dependencies remain subject to their own security policies and licenses.
