KARTU IDENTITAS PENDUDUK

Filter berdasarkan NIK

Masukkan NIK untuk mencari data. Kartu hanya akan ditampilkan setelah semua kolom wajib lengkap. Foto tidak digunakan. Pratinjau ini untuk keperluan internal dan bukan dokumen identitas resmi.

Muat file Excel terlebih dahulu, lalu cari penduduk menggunakan NIK.

Periksa dan lengkapi data kartu

Kolom yang sudah tersedia dari Excel akan terisi otomatis. Lengkapi bagian yang masih kosong sebelum menampilkan kartu.

Data pelengkap disimpan hanya di browser/perangkat ini dan tidak dikirim ke server serta tidak mengubah file Excel sumber.
